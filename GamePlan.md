# Dibbler Escape

## Main Game Loop
* You (a tourist) spawns in to a procedually generated maze.
* There spawns a number of dibblers (street merchantes)
* Your goal is to make it back to the safety of your hotel with some of your 3 cash left in your wallet.
** In some leves you can make it back to the guide bus or atv ride train to get away from the dibblers.
* If a dibbler catches you, you throw money at them, and they go away.

* If you run out of cash, you are game over.

### Traps and Features
* There are cats roaming the streets, if you come across one, you must stop to pet the cat

## Engine Choices
* The game engine is a html5 web page, and is run by a javascript engine

## Art Style
* Game Name is "Dibbler Escape"
* Cartoony style. You a white tall male, wearing cargo shorts and a hawaii shirt and a tropic hat.
* Dibblers are wearing long flowy clothes
